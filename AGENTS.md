# Дневник дел

- Полностью локальное приложение: Next.js / React / Node.js и PostgreSQL.
- Не публиковать сайт и не добавлять зависимости от Sites, Neon или входа через ChatGPT.
- Основной запуск после клонирования: `npm run local:up` (Node.js и Docker Compose).
- Приложение доступно только на `127.0.0.1:3000`; порт БД не публикуется.
- `app/page.tsx` и `app/globals.css`: интерфейс. `lib/server/`: авторизация, SQL и аудит.
- `db/schema.sql`: схема PostgreSQL; миграции выполняет владелец БД, не runtime-роль `test`.
- Все запросы задач и аудита ограничиваются пользователем из серверной сессии.
- Изменение задачи и запись аудита атомарны. Аудит не редактируется через приложение.
- Секреты генерируются локально в игнорируемом `.env.docker`; ручная разработка использует `.env.local`. Не выводить и не коммитить секреты.
- `npm run local:down` сохраняет данные. Не удалять Docker volume с данными без явного поручения.
- Проверки: `npm run typecheck`, `npm run build`, `TEST_BASE_URL=http://localhost:3000 npm run test:integration`, `npm run test:security`.
- Общий лимит авторизации проверяется до пользовательского; заголовки клиента не выбирают бюджет попыток. Устаревшие ключи удаляются ограниченными порциями.
- Проверять изоляцию пользователей, журнал, регистрацию и перезапуск на реальной PostgreSQL.
- Сохранять текущие задачи пользователя и чужие изменения; не менять другие БД и сервисы.
